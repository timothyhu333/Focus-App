# MyFocus Personal OS

A complete local-first productivity app for goals, projects, tasks, daily planning, focus sessions, notes, habits, journaling, achievements and analytics.

## Replace your current Vite project
Copy everything from this folder into the root of your `myfocus-app` repository, allowing files to be replaced. Then run:

```bash
npm install
npm run dev
```

After testing:

```bash
git add .
git commit -m "Build full MyFocus personal operating system"
git push
```

## Data
Data is stored in browser localStorage. Use Settings > Export backup before clearing browser data or moving devices. Cloud sync and authentication are not included in this local-first build.
